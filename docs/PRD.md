# PRD

## 1. Why - 목적

- **상위 목표와 일상 업무의 정렬**: 년간-월간-주간-일간으로 이어지는 위계적 구조를 통해 장기 목표가 일상 할 일로 구체화되도록 지원
- **실시간 진행 상황 시각화**: 일간 및 주간 진행률 자동 계산을 통해 목표 달성률을 직관적으로 파악 및 관리
- **직관적인 상태 변경**: 칸반/드래그 앤 드롭 방식을 채택하여 사용자의 상태 업데이트 피로도 감소 및 작업 효율성 증대

## 2. Who - 타깃 사용자

- **장기 목표 달성이 필요한 개인/직장인**: 연간/월간 목표를 수립하고 이를 매일의 실행 과제로 분할 관리하고자 하는 사용자
- **시각적 공정 관리를 선호하는 생산성 관리자**: 상태별(예정/진행중/완료) 드래그 앤 드롭 작업 업데이트 인터페이스를 선호하는 사용자

## 3. User Flow

- **목표 수립 Flow**: 1년 계획 입력 ➔ 월간 계획 연결/등록 ➔ 주간 계획 세분화 ➔ 일간 할 일(Task) 생성
- **업무 수행 및 상태 업데이트 Flow**: 일간 할 일 확인 ➔ 드래그 앤 드롭으로 상태 변경(예정 ➔ 진행중 ➔ 완료) ➔ 일간/주간 진행률 자동 갱신 확인
- **수정 및 삭제 Flow**: 할 일/계획 선택 ➔ 내용 수정 또는 삭제 ➔ 상위 계층 진행률 연동 업데이트

## 4. 기능 요구사항

### P0 - 핵심기능

#### 할 일 CRUD 및 계층 구조 연결

- **1년 계획**: 연 단위 목표 생성/조회/수정/삭제
- **월간 계획**: 특정 1년 계획을 상위 개체로 지정하여 생성/조회/수정/삭제 (1년 계획 : 월간 계획 = 1 : N)
- **주간 계획**: 특정 월간 계획을 상위 개체로 지정하여 생성/조회/수정/삭제 (월간 계획 : 주간 계획 = 1 : N)
- **일간 할 일**: 특정 주간 계획을 상위 개체로 지정하여 생성/조회/수정/삭제 (주간 계획 : 일간 할 일 = 1 : N)

#### 상태 관리 및 드래그 앤 드롭

- **3단계 상태 정의**: 예정(To Do), 진행중(In Progress), 완료(Done)
- **D&D 상태 변경**: 카드 형태의 할 일을 드래그하여 상태 컬럼 간 이동 시 DB 상태값 실시간 업데이트

#### 진행률 자동 반영 계산 로직

- **일간 진행률**: (당일 완료된 일간 할 일 수 / 당일 전체 일간 할 일 수) * 100 (%)
- **주간 진행률**: (해당 주차 완료된 주간 계획 및 하위 할 일 완료 배점 / 해당 주차 전체 계획 수) * 100 (%)
- **상위 자동 연동**: 하위 일간 할 일의 상태 변경 즉시 상위 주간 및 일간 진행률 프로그레스 바 반영

### P1 - 추가기능

- **기간별 뷰 전환 (Calendar / List / Board View)**: 일일, 주간, 월간, 년간 단위별 필터링 및 대시보드 시각화
- **미완료 항목 이월(Rollover) 기능**: 당일 미완료 처리된 '예정/진행중' 할 일을 익일 일간 할 일로 자동/수동 이월
- **계층별 진행률 롤업(Roll-up) 확산**: 주간 진행률 집계를 기반으로 월간 및 년간 목표 달성률 자동 추산 연동
